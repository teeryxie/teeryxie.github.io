Multimodal Systems · ICML 2026

Training-Free Multimodal LLM Orchestration

How can an interactive omni-modal assistant coordinate heterogeneous expert models without retraining a monolithic model?

A large language model (LLM) controller schedules vision and audio experts without additional integration training. Shared cross-modal memory supports context reuse, while the interaction layer supports simultaneous listening and response generation, including interruptions.

First author; scheduling, full-duplex speech interaction, and cross-modal memory

Benchmark · arXiv

SocialOmni

Existing omni-model benchmarks underrepresent time-sensitive audio-visual social interaction.

Query-time-bounded audio-visual evidence supports separate evaluation of speaker identification, turn-entry decisions, and response generation. The current release includes 2,000 perception items, 200 interaction-generation items, and results for 11 omni models.

First author

Long Video · CVPR 2026

Long-video Frame Selection

Long-video models spend substantial computation on redundant frames while missing sparse semantic events.

Event anchors and wavelet-detected semantic boundaries guide adaptive frame allocation without training an additional selector.

Efficient Inference · AAAI 2027

Correct While Verifying

Speculative decoding discovers incorrect draft tokens only after final verification, then discards the entire suffix following the first rejection.

Intermediate target-model states predict correct continuations early, seed correction branches, and verify original and corrected drafts in parallel.
